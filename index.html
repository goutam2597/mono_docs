FAQs

Questions, answered.

What's included in the suite?

The Laravel storefront with 8 themes, the admin panel, the vendor panel, and three Flutter apps — customer, vendor and SMS gateway — plus the REST API and the guided installer.

What are the server requirements?

Any host running PHP 8.3 with the pdo_mysql extension and MySQL 8 — the same stack Laragon, cPanel or a plain VPS provides. The Flutter apps build with Flutter 3.

Do you help with installation?

The guided installer walks you through database, admin account and store setup step by step, and verifies the build manifest before you go live.

Which payment gateways are supported?

Cash on delivery plus card gateways through the payment module, with refunds back to the gateway, the customer wallet, or an auto-generated one-shot coupon.

How do notifications work?

Email (SMTP), SMS via Twilio or your own Android phone through the gateway app, WhatsApp via the official Cloud API, and push notifications through Firebase FCM.

Is the code localized?

English, Bengali and Arabic ship in the box with full RTL mirroring across the storefront, panels and apps — and the AI engine translates product content between them.
